# Modal de produto bloqueado

No painel, abra **Produtos → produto → Geral → Modal do produto bloqueado**.

- **Título do modal:** deixe vazio para usar o nome do produto.
- **Texto do modal:** personalize a apresentação com parágrafos; vazio usa a descrição do produto.
- **Imagem:** opcional, até 2 MB. Um mockup quadrado é recomendado; a imagem aparece inteira. É possível remover a imagem salva.
- **Texto do botão:** padrão “Quero acessar”.
- **Checkout do produto:** destino do botão. Se houver checkout de aluno com desconto, esse link tem prioridade e abre diretamente.
- **Prévia:** salve o produto e use “Visualizar modal de produto bloqueado” para conferir o resultado nas cores da loja.

O produto permanece bloqueado até a confirmação da compra. Na vitrine, a capa fica em preto e branco com cadeado no canto. Clique na capa para abrir o modal; o checkout abre em outra aba. Escape, o botão Fechar e um clique fora fecham o modal.

Este modal é usado para produtos ainda não adquiridos. A oferta de upgrade Básico → Completo continua com os campos próprios de upgrade.
