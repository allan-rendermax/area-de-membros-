# Visualizar a área como aluno

Disponível no painel após a publicação desta versão.

1. Entre normalmente no painel administrativo.
2. Salve as alterações do produto, dos módulos e dos conteúdos.
3. Clique em **Visualizar como aluno ↗**:
   - No cabeçalho do painel, abre a vitrine da loja selecionada.
   - Na edição de um produto salvo, abre diretamente aquele produto.
4. Navegue pela nova aba. Para conferir novas alterações, salve no painel e atualize a prévia.
5. Use **Voltar ao painel** para retornar à administração sem encerrar o login.

A prévia usa o visual das mesmas telas do aluno e inclui produtos, módulos e itens em rascunho. O acesso aparece como **Completo**, permitindo conferir todo o material antes de publicá-lo. Ela mostra somente alterações já salvas; não publica o produto.

Não é necessário criar um aluno, informar outro e-mail, simular uma compra ou conceder acesso manual. A faixa **Modo de prévia** identifica essa navegação. O botão **Concluir** fica desativado e acessos, downloads e progresso não são registrados como atividade de aluno.

O modo exige uma sessão administrativa válida em cada página e ao abrir arquivos. O parâmetro `?previa=1` sozinho não concede acesso. As páginas normais dos alunos mantêm as regras de compra, nível de acesso e publicação.

A prévia não simula compras específicas, conteúdos bloqueados de uma conta Básica ou o histórico de um aluno real. Para conferir quais produtos um cliente possui, continua disponível **Clientes → Ver como aluno**.
